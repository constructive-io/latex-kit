# Examples

Fictional documents used to test latex-kit end to end. Every name, address
and amount in them is invented, and the contract-shaped ones are not legal
advice. CI builds each one twice and fails unless the PDFs are
byte-identical.

| Example | Shows |
|---|---|
| [`letter/letter.tex`](letter/letter.tex) | `latex-kit render`: a plain `.tex` file → PDF |
| [`workspace/`](workspace) | A full project: templates, schemas, shared data, snippets, clauses, records |
| [`import/offer-letter.docx`](import) | `latex-kit import`: a Word document with `{{placeholders}}` becomes a template and a starter schema (made from `offer-letter.md` with pandoc) |

## The workspace

| Document | Template | Shows |
|---|---|---|
| `documents/invoice-0001.ts` | `invoice` | A TypeScript record that computes its totals; `\each` in a table; `money`, `percent`, `words`; a shared letterhead snippet |
| `documents/nda-placeholder-labs.yaml` | `nda` | Versioned clauses from `clauses/nda/` with `\clauseref` cross-references, `\when`/`\otherwise`, lists, `\docid` in the footer, signature blocks that change for `signed` |
| `documents/letter-sample-kk.json` | `letter-ja` | Japanese and English in one letter (LuaTeX-ja, IPAex fonts), `ja-JP` dates and yen |

Companies and people live once in `data/` and are pulled in with
`{ "$ref": "orgs/example-widgets" }`. Note `Placeholder Labs & Co. (100%
fictional)`: the `&` and `%` print as written because every value is escaped.

```bash
pnpm build            # from the repo root, builds the CLI
cd examples/workspace
node ../../packages/latex-kit/dist/cli.js check
node ../../packages/latex-kit/dist/cli.js build --final --verify
node ../../packages/latex-kit/dist/cli.js build --variant blank
```

`templates/*/types.d.ts` and `*.schema.json` are generated by
`latex-kit typegen`; CI fails if they are out of date.
